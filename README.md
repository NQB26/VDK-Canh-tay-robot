# VDK-Canh-tay-robot

Cánh tay robot 6 bậc tự do dùng STM32.

- `3D PARTS/`: các chi tiết in 3D (STL)
- `RobotArm/`: project STM32F103 + script ROS2 tính động học ngược (`scr/`)
- `RobotArm_6DOF/`: project STM32F411 điều khiển 6 servo, nhận lệnh qua UART (laptop / BLE)
- `control_ui/`: **giao diện web điều khiển bằng thanh trượt hoặc joystick** trên máy tính / điện thoại, xem [control_ui/README.md](control_ui/README.md)
